# SRW64 tests

The tests compile 64-bit Windows programs, recompile them using SRW64, build the recompiled programs and compare their output with the output of the original programs.

Requirements: NASM, MinGW-w64 (`x86_64-w64-mingw32-gcc`, `dlltool`, `windres`), Wine, GCC, Python 3.

    ./run_tests.sh

Environment variables:

* `SRW64` -- path to SRW64 executable (default: `../SRW64.exe`)
* `WORK` -- work directory (default: new temporary directory)
* `WINDOWS_DIR` -- directory with original Windows executables (*sort.exe*, *where.exe*), for example `/mnt/windows/Windows/System32` -- enables test of executables compiled by Microsoft
* `FH4_EXECUTABLES` -- list of executables built by Visual Studio 2019+ (with `__CxxFrameHandler4`), their C++ exception handling data is verified after recompilation

Tests:

* *mingw_c* -- C program compiled by MinGW (recompiled including CRT startup code): switch tables, function pointers in data, callbacks, floating point, imports -- win64 executable is run using Wine
* *msvc_patterns* -- freestanding program with code patterns generated by MSVC (image relative jump tables, two-level jump table with byte index table, image relative array addressing) and GCC jump table -- win64 executable is run using Wine, elf64 version is linked with *runtime_linux.c* (implementation of used Windows functions) and run natively on Linux
* *fh4* -- C++ exception (catch block with continuation address relative to function start) described by `__CxxFrameHandler4` data -- the recompiled code is shorter, so the program works only if the offsets in the data are converted; the data is also verified by *verify_fh4.py*
* executables with `__CxxFrameHandler4` data (optional) -- the data is verified by *verify_fh4.py*
* Windows executables (optional) -- *sort.exe* and *where.exe* from Windows 10/11

Scripts:

* *roundtrip_win64.sh* -- recompiles any 64-bit Windows executable into new Windows executable: `roundtrip_win64.sh <executable> <work directory> [console|windows]`
* *mkimplibs.py* -- creates import libraries for the imports used by the generated assembler file
* *verify_fh4.py* -- compares `__CxxFrameHandler4` data of original and recompiled executable: `verify_fh4.py original.exe recompiled.exe`
